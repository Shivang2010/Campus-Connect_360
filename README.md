# CampusConnect 360

A Flutter starter project for a student campus community app.

## Included

- Flutter + Dart
- GetX routing and reactive state
- Dio REST API service
- Firebase-ready Firestore service
- Feature-based folder structure
- Lost & Found
- Events
- Marketplace
- Notes
- Complaints

## Run

1. Extract the ZIP.
2. Open the project in Android Studio/VS Code.
3. Run `flutter pub get`.
4. Configure Firebase for your Android/iOS app using FlutterFire.
5. Run `flutterfire configure`.
6. Replace/extend the placeholder feature screens with Firestore CRUD.
